What this website is

ndclients.co.in is the home of Nirmaldhara Micro Foundation’s operations console. The public page explains the work. The staff login opens the web console used by Admin and Branch Manager.

The same system feeds the Android field app: applications, customers, dialer recordings, attendance, and GPS. Nothing on the public page replaces a branch visit. It shows how those visits are captured and approved.

Why it exists

Field teams meet customers away from the office. Paper files and unlogged calls make it hard to know who was met, what was said, and whether a branch has signed off.

This platform keeps one chain: the officer files the application, the branch checks it, and admin publishes it. Calls, attendance, and location sit beside that chain so supervisors can see the day’s work.

On the platform

One record for the customer, the call, and the visit.

A new customer starts as an application: name, mobile, identity details, shop address, and live GPS. After approval, the person appears on the customer list. Calls placed from the field app are meant to be recorded and stored with the call log. Attendance uses face and GPS where policy requires it. Supervisors watch live tracking from the web console.

Who signs in, and from where

The mark you see above is the foundation logo: the letters, the leaf, and the coins. Staff use the same name on the web console and on the phone.

Admin

Sees every location. Publishes applications, creates users and roles, manages branches, and opens pay slips. An application filed by admin does not wait for anyone else.

Branch manager

Works inside one branch. Reviews field-officer applications, then sends them to admin. If the manager files the application, only admin approval is left.

Branch manager login

Field officer

How an application moves

The path depends on who submits it. Status names on the console match these steps.

1

Field officer files the visit

On the mobile app the officer enters the customer, captures the shop location, and submits. The application waits for the branch manager.

2

Branch manager reviews

The branch manager approves or rejects applications from their location. An approval sends the file to admin. If the branch manager submits the application themselves, it skips the branch step and goes straight to admin.

3

Admin publishes

Admin gives the final approval, or rejects it. When admin submits an application, it is published immediately and no further approval is required. A published application creates the customer record.

4

Daily work stays attached

After that, calls, attendance, and GPS routes continue under the same staff account and branch, so the dashboard can show customers, calls, and who is in the field.

Questions

What is this website for?

It explains Nirmaldhara Micro Foundation’s field system and opens the staff console. Customer files are created on a visit, not from a public form on this page.

Who can log in here?

Admin and Branch Manager, with the employee ID or mobile and password issued to them. Field officers use the mobile app.

How does approval work?

A field officer needs the branch manager and then admin. A branch manager needs only admin. Admin publishes immediately.

Where do call recordings go?

Calls placed from the field app are recorded on the phone and uploaded with the call log so a supervisor can play them from the console.

Contact and access

This website does not take public loan applications. Customer onboarding is done by field staff during a visit.

Admin and Branch Manager use Staff login with the employee ID or mobile number issued by Nirmaldhara Micro Foundation. Field officers use the Android app with the same kind of login.
